# 新手引导：Agent 配平工具

## 30 秒理解这个工具

你要做的事：**比较「新 agent」和「老 agent」谁更好**（更少转人工、满意度更高……）。

为什么不能直接比：新 agent 是**定向灰度**上线的——先上新的人（高会员、特定意图）本身就和老 agent 那批人不一样。直接比，差异里混着「人的差异」，不是「agent 的差异」。

工具做的事：用**配平（PSM）**，把「新老两拨人」按维度配成**可比的两队**，输出谁配谁。配完之后，你拿这两队去比任何结果，差异才公平。

## 原理（给第一次用的人）

新 agent 不是随机上线的，它先推给了特定的人。所以「新 agent 处理的进线」和「老 agent 处理的进线」**本来就不是一拨人**，直接比它们的结果不公平。

**工具做的事**：给每条「新 agent 的进线」，在「老 agent 的进线」里找一个**其他维度上最像**的，配成一对。配完后两队就「长得一样」了（除了一个是新、一个是老）。

> **打个比方**：新教练只教尖子生、老教练教普通生。直接比考试成绩，新教练必胜——但那是学生底子好，不是教练好。工具就是给每个尖子生，在普通生里配一个「基础、学习时长都一样」的，配完再比谁进步大，才公平。

## 一个关键口径：「新 agent」指什么？

- **可以触发**（推荐）：被分到「新 agent 灰度组」的进线，哪怕后来转人工了也算。分组在进线前就定了，干净。
- **触发过**：实际被新 agent 接手的进线。但新 agent 会把难问题转人工——难问题被踢掉后，剩下的都是简单问题，结果失真。

**填处理方列时，填「是否被分到灰度组」，不要填「实际谁处理」。**

## 5 分钟走通一遍（用自带示例）

1. `npm start`，浏览器打开 http://localhost:5175
2. 把 `examples/sample.csv` 内容粘贴进去（或「选择文件」），**会自动解析**
3. 映射列（见下表），点「运行配对」
4. 看结果

## 数据格式（一行 = 一条进线）

CSV：
```csv
session_id,agent,member_level,prev_effective,intent
s_001,1,3,1,complaint
s_002,0,2,0,consult
```

JSONL：
```jsonl
{"session_id":"s_001","agent":1,"member_level":3,"prev_effective":1,"intent":"complaint"}
```

| 列 | 必需？ | 含义 |
|---|---|---|
| session_id / user_id | 建议 | 实例 id（配对结果的标识） |
| agent | **必需** | 谁处理的：新 agent=1，老 agent=0 |
| member_level 等 | 维度 | 进线时就确定的特征，用来配对 |

**三条铁律**：
1. `agent`（处理方）是**唯一不可缺**的列。
2. **「新 agent」填「是否被分到灰度组」（可以触发），不要填「实际谁处理」（触发过）**——新 agent 会把难问题转人工，按实际处理算会把难问题踢掉、只剩简单问题，结果失真。
3. 维度只能放「进线那一刻就已知」的特征，别放结局同期之后的量。

## 映射列怎么填

| 字段 | 怎么填 |
|---|---|
| 实例列 id_col | 选标识每条进线的那列（session_id 或 user_id） |
| 处理方列 treat_col | 选「谁被分到新 agent 灰度组」那列（0/1），不是实际谁处理 |
| 新 agent 取值 treat_value | 新 agent 在这列里的值：0/1 填 1，old/new 填 new |
| 维度 cov_cols | 勾「进线时就确定」的特征，多选无妨 |

## 结果怎么读

- **两组在维度上是否可比**：配平后最大差异度 < 0.1 = 可比。这是结果可信度的根基。
- **各维度的分布对比**：配平前两组分布有差异，配平后应基本重合——最直观的证据。
- **配对关系**：完整配对在 `matched_cohort.csv`（谁配谁），可下载。

## 常见问题

**Q：维度该选哪些？**
A：选「可能影响『谁被灰到新 agent』和『结果』」的进线特征——会员等级、意图类型等。拿不准就多选，工具会告诉你配平结果。

**Q：treat_value 填什么？**
A：新 agent 在「处理方列」里的那个值。列是 0/1 就填 1，是 old/new 就填 new。

**Q：报「处理方列只有单一取值」？**
A：treat_value 没对上——去查处理方列里新 agent 的实际取值，照实填。

**Q：配平后差异度 ≥ 0.1（不可比）？**
A：新老两拨人在某些维度上配不平。看分布对比图里哪些维度错开，考虑：多加维度、或缩小分析人群。
