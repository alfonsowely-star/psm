# PSM 测试数据集说明（testset_agent）

一个**带已知真实因果效应、强定向灰度混杂、连续强相关协变量**的客服会话数据集，专门用来测试 `agent-psm` 工具。它的特点是：**朴素对比会给出错误结论（方向相反），只有正确配平后才能还原真值**。

---

## 1. 数据集概览

| 项 | 值 |
|---|---|
| 文件 | `examples/testset_agent.csv` |
| 会话数 n | **9056** 条 |
| 用户数 | 3600（同一用户 1–4 条进线，用于聚类） |
| 新 Agent（agent=1）/ 老 Agent（agent=0） | 5878 / 3178（处理比例 64.9%） |
| 时间跨度 | 2026-09-01 ~ 2026-10-21 |
| 主结局 | `transferred`（是否转人工，0/1，完整） |
| 次结局 | `satisfied`（满意度，0/1，**约 29.9% 缺失**） |
| 生成脚本 | `examples/make_testset.py`（可复现、可调参，seed=20261025） |
| 完整配置 | `examples/testset_config_full.json` |

## 2. 数据字典

| 列名 | 类型 | 角色 | 含义 |
|---|---|---|---|
| `session_id` | string | 实例 id | 会话 id |
| `user_id` | string | 聚类 id | 用户 id（cluster bootstrap 用） |
| `ts` | datetime | 时间 | 进线时间戳（为 FR-10 时间混杂预留） |
| `agent` | 0/1 | **处理方** | 1=新 Agent（treated），0=老 Agent |
| `member_level` | 1–5 | 协变量 | 会员等级（灰度强相关，配平前 SMD≈0.97） |
| `monthly_orders` | 连续 | 协变量 | 月订单数（与会员等级相关 ρ≈0.62） |
| `history_complaints` | 计数/连续 | 协变量 | 历史投诉次数（高投诉体质） |
| `intent` | 4 类 | 协变量 | complaint / consult / billing / refund |
| `wait_minutes` | 连续 | 协变量 | 排队时长（与投诉意图相关 ρ≈0.50） |
| `prev_effective` | 0/1 | 协变量 | 上一次进线是否有效 |
| `transferred` | 0/1 | **主结局** | 是否转人工（新 Agent 使其下降） |
| `satisfied` | 0/1 | 次结局 | 满意度（约 30% 非响应，空值） |

> 所有协变量均为「进线时已确定」的预处理特征，满足 PRD 硬约束（无后处理变量）。

## 3. 已知真值（DGP 内置，用来判对错）

- 新 Agent 在 logit 尺度的真效应 `tau_logit = −0.32`；
- 折算成 treated 人群的真实风险差 **ATT ≈ −0.0608（约 −6.1 个百分点）**，即新 Agent 让转人工率下降约 6pp；
- 灰度规则使高等级、高频、历史有效、投诉意图的会话更易进新 Agent，而这些画像本身更容易转人工，制造强正向混杂。

## 4. 基准答案（实跑，供对照）

| 指标 | 结果 | 解读 |
|---|---|---|
| **真实 ATT** | **−0.0608** | 基准，正确答案 |
| 朴素对比 NAIVE | **+0.0338** | ❌ 方向都反了，混杂偏差约 9.5pp |
| IPTW | **−0.0535** | ✅ 接近真值（误差 +0.007） |
| 双重稳健 DR | **−0.0576** | ✅ 最接近真值（误差 +0.003） |
| 匹配 MATCH | **−0.0514** | ✅ 检出，但三法中最不精确（见审查报告马氏 bug） |
| IPW 95% CI | [−0.075, −0.029] | 不含 0，显著 |
| DR 95% CI | [−0.079, −0.033] | 不含 0 |
| 匹配 95% CI | [−0.078, −0.017] | 不含 0，区间最宽 |
| 倾向模型 AUC | 0.766 | 灰度定向性明显 |
| 配平 max\|SMD\| | 0.971 → **0.045** | 达标（<0.1），平均偏倚降低 93.7% |
| 权重 ESS | 4314 / 9056（47.6%） | 最大权重 12，99 分位 8.1 |
| 支撑域外 treated | 13 条 | overlap 告警测试点 |
| 置换检验 | **p < 0.005**（200 次无一达到观测效应） | 方法有效应 |
| E-value | 1.535（RR 0.879） | 需 RR≈1.54 的未观测混杂才能推翻 |
| MDE | 0.0425（4.3pp） | 小于 6pp 效应，故有能力检出 |

**判读标准**：三法方向一致、都落在 −0.05 ~ −0.06、CI 不含 0、配平达标、置换 p 显著，即视为工具工作正常、能正确识别「新 Agent 降低转人工」。若看到 +0.03 之类的正向结论，就是被混杂带偏了。

## 5. 怎么跑

### 方式 A：Web 界面（只看配平，当前产品未接效应）

```bash
npm start          # 打开 http://localhost:5175
```

上传 `examples/testset_agent.csv`，列映射：实例 id=`session_id`，处理方=`agent`（新取值 `1`），维度勾选全部 6 个协变量。
> 注意：当前 Web/`analyze.py` 只做配平，不输出效应（审查报告 P1-2）。配平基准：max|SMD| 后≈0.067，达标。

### 方式 B：命令行完整效应分析（推荐，含三法/CI/证伪）

用 `examples/run_full.py`（补齐 `run_analysis` 接线的临时入口）：

```bash
python examples/run_full.py --data examples/testset_agent.csv \
  --config examples/testset_config_full.json --outdir runs/testset_benchmark
```

结果同时写入 `runs/testset_benchmark/effect_report.json`。Python 请用含 numpy/pandas/scipy/sklearn 的环境（本机为 Anaconda Python 3.8）。

### 方式 C：仅配平（analyze.py / Web 后端同款）

```bash
cd python
python analyze.py --data ..\examples\testset_agent.csv \
  --config ..\examples\testset_config_full.json --outdir ..\runs\test_bench
```

## 6. 推荐的「破坏 / 压测」实验（对照审查报告）

1. **零效应复现**：把 `make_testset.py` 里 `TAU_LOGIT` 改为 `0.0` 重新生成，三法应≈0、CI 含 0、置换 p 不显著。
2. **协变量缺失崩溃（P1-1）**：在某协变量随机注入 NaN，`run_analysis` 会抛 `ValueError`。
3. **匹配法偏差（P0-1）**：只用连续变量（monthly_orders / wait_minutes / history_complaints）做协变量，对比 MATCH 与 IPW/DR 的偏离，连续强相关下匹配更不精确。
4. **删协变量制造残余混杂**：从配置里删掉 `member_level` / `intent`，三法会向朴素方向偏，观察配平证书与结论如何变化。
5. **满意度缺失结局**：把 `outcome_col` 改成 `satisfied`，工具会自动剔除约 30% 非响应行（输出"结局缺失行数"）。
6. **支撑域**：调大灰度系数（如把 `logit_t` 中 member 系数调大）制造更严重的不重叠，观察 overlap 告警与 ESS 暴跌。
