Agent 配平 把新老两拨人配成可比的两队

新手引导

新 agent 不是随机上线的，新老两拨人本来就不一样。工具给每条「新 agent 进线」在老 agent 里找一个维度上最像的配成一对，配完后两队才可比。

三步

① 粘贴数据（自动解析）→ ② 映射列 → ③ 运行。

必填字段

字段填什么
实例列每条进线的 id（如 session_id）
处理方列谁新谁老（如 agent，新=1）
维度用来配对的进线特征，勾上即可
一条铁律：「新 agent」填「是否被分到灰度组」，不要填「实际谁处理」——否则转人工的难问题会被踢掉、只剩简单问题，结果失真。

勾「是否输出效果」会多出结局/用户等字段；完整说明见 docs/GUIDE.md。
